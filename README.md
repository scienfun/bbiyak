# 삐약 (MedCheck AI)

약봉지/처방 라벨 이미지를 기반으로 복약 안전성을 **정보 제공 목적**으로 점검하는 Next.js 웹앱입니다.

## 구현 범위 (시트 TASK-001 반영)

- 필수 입력
  - 나이, 성별, 기저질환(없음 선택), 약봉지 이미지
- 선택 입력
  - 약물 알레르기, 임신/수유, 복용 중 약/영양제, 음주/흡연, 사용자 질문
- 검증
  - 나이 숫자형, 이미지 형식(jpg/jpeg/png), 파일 크기 제한(8MB)
- 파이프라인
  - OCR 추출(기본 fallback, 선택적 OpenAI Vision)
  - 약 정보 구조화(name/ingredient/dose/freq/days/confidence)
  - 안전성 분석(응급 신호 감지, 위험도 분류, 주의사항/질문 생성)
- 출력 고정 8섹션
  1) 한 줄 요약
  2) 인식된 처방 정보 (확인 필요)
  3) 핵심 안전 체크
  4) 기저질환/연령/성별 관점 주의사항
  5) 흔한 부작용 & 모니터링 포인트
  6) 복용/보관/상호작용 일반 주의
  7) 의사/약사에게 확인할 질문
  8) 확신도 & 한계
- 결과 상단
  - 고정 면책 문구
  - 응급 가능성 탐지 시 경고 배너
- 다운로드
  - 의사/약사에게 보여주기용 요약 텍스트 다운로드

## 기술 스택

- Next.js 16 (App Router, TypeScript)
- React 19

## 빠른 시작

```bash
npm install
npm run dev
```

브라우저: `http://localhost:3000`

## 환경 변수 (선택)

`.env.local` 파일에 설정:

```bash
OPENAI_API_KEY=your_key_here
OPENAI_VISION_MODEL=gpt-4.1-mini
```

- 설정 시 OCR을 OpenAI Vision으로 시도
- 미설정/실패 시 fallback OCR 사용

## 보안/개인정보 설계 메모

- 이미지는 DB에 저장하지 않고 요청 단위로 처리
- 분석 결과도 서버 저장 없이 세션성 반환
- 본 서비스는 진단/처방 변경 지시를 제공하지 않음

## 한계

- OCR 정확도는 이미지 품질과 모델 상태에 따라 달라짐
- 실제 처방 의도/개인 특수 상황은 의료진의 최종 확인이 필요
